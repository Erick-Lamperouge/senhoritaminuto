# Superfície pública e organização de informações
Em 26/11/2026 a API GitHub confirmou que senhoritaminuto, estrutura-dos-blogs e futebolando são públicos. Branches de trabalho e rascunhos versionados são legíveis por terceiros; noindex não é controle de acesso. JavaScript, HTML, CSS, imagens, conteúdo e os links de jogos enviados ao navegador também podem ser copiados, mesmo com repositório privado.
A configuração legada contém IDs públicos de AdSense/Analytics/verificação e campos demonstrativos de apoio/pagamento, referências a secrets do Actions, não valores dos segredos. Triagem direcionada de configurações e nomes de arquivo nos trees atuais não localizou padrões examinados de chaves privadas/tokens. Há texto pessoal publicado por decisão anterior (dedicação e homenagem), que deve ser revisado pelo responsável se desejar restringir. Não imprimir valores de pagamento/credenciais nem presumir que placeholders são aptos para uso.
Gate scripts/check-public-surface.mjs: verifica arquivos de texto rastreados da versão portal, v2 do núcleo, editorial pinado e dist; sinaliza tipos de arquivos indevidos e padrões específicos de tokens/keys, registrando somente caminho e categoria. Não faz varredura de histórico completo, binários/esteganografia, credenciais de Actions, dependências transitivas, permissões do Vercel ou aplicações incorporadas. Não certifica ausência de segredos nem protege contra cópia.
Recomendação: manter portfólio informativo público; código estratégico, planejamento privado, dados de audiência não agregados, credenciais de APIs, tokens, chaves privadas, seeds, dados de clientes e checkout administrativo fora dos repos públicos e de localStorage/sessionStorage. Nunca publicar CPF, telefone ou e-mail pessoal como chave Pix sem avaliar exposição; preferir chave aleatória de conta adequada. Configuração futura de Pix/crypto apenas endereços de recebimento públicos, sem chave privada. Revisar contratos/licenças e copyright; não adotar bloqueio de botão direito ou ofuscação como proteção. Qualquer segredo exposto deve ser revogado/rotacionado, não apenas apagado do commit.
Não alterar visibilidade sem plano de migração. GitHub Pages privado no Free pode derrubar o site e exigir atualização de DNS; os checkouts entre repositórios também precisariam de acesso autorizado. Ver https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility e https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html. Aplicações Jack-UP e demais iframes são serviços distintos e não foram auditadas por dentro.
